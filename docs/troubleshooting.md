# 踩坑与交接记录

## 从 ZIP 迁移到链接安装

- ZIP 版以前解压到 `~/SillyTavern/data/default-user/extensions/preset-workbench`。选择安装给当前用户时，酒馆会按仓库名新建 `st-preset-workbench`，两个目录会各自被加载。
- 迁移前关闭旧工作台页面，再把 ZIP 版目录移出 `extensions`。下面的命令会先创建一个独立备份目录，再移动旧扩展。

```bash
cd ~/SillyTavern &&
test -f data/default-user/extensions/preset-workbench/manifest.json &&
backup_dir="$(mktemp -d "$PWD/preset-workbench-backup.XXXXXX")" &&
mv -- data/default-user/extensions/preset-workbench "$backup_dir/" &&
printf '旧版已备份到 %s\n' "$backup_dir"
```

- 刷新酒馆，按 [README](../README.md#通过链接安装) 安装 GitHub 版，安装后再刷新一次。同一酒馆地址和浏览器里的工作台草稿仍可读取，快照保存在原酒馆账号的扩展设置里。
- GitHub 版验证好后，可以删除备份和手机「下载」目录里的旧 ZIP。旧 ZIP 文件保留在「下载」目录时，酒馆也不会加载它。

## 左下角菜单与真实数据

- 手机顶部工具区容易挤满，安装后从聊天输入框左下角的 **☰ → 预设工作台** 进入。更新扩展后，先刷新原酒馆页面，再从这个入口重新打开工作台。
- 能打开工作台，只验证了扩展入口。看到示例内容时，检查工具栏是否有 **从酒馆选预设**，然后选一份真实预设并点 **载入草稿**。
- `0.1.1` 增加左下角入口，`0.1.2` 增加读取已保存的聊天补全预设。世界书另有 **从酒馆选世界书** 入口，需要启用酒馆助手。保留原酒馆标签页，工作台通过同源酒馆页面读取数据，编辑结果进入草稿。
- 2026-11-18 手机实测：用户已能在工作台看到酒馆里的预设。首次打开或使用「继续聊」时，默认仍显示测试预设，容易让人以为没有连上。
- `0.1.3` 默认载入酒馆当前使用的聊天补全预设。已有编辑或自行导入的草稿时可点「打开酒馆当前预设」选择切换，切换后可用撤销恢复。
- AI 会话的「AI 模型」读取同一酒馆地址下 ST-ApiManager 已存的分组。列表缺少分组时，核对是否用同一浏览器和地址。例如 `127.0.0.1` 和 `localhost` 的浏览器存储独立。其他来源可在 API 管理器切换后选「沿用酒馆当前连接」。

## 长任务怎么换窗口

- 从 [文件目录表](../FILE-INDEX.md) 选相关文件。先核对仓库、分支和最新提交，再按行查看有关源码。大包、构建产物、压缩 JS 和 Base64 由脚本处理，只回传必要摘要。
- 当前 Work 窗口的助手拿不到实时上下文余量。遇到长任务，可以在功能交付或排查暂停时留一段短交接，记下仓库、分支、提交、涉及路径、最后一个实测结果和下一步。
- 接手这个项目时，先读根目录 `FILE-INDEX.md` 和这份记录。当前用户的链接安装目录是 `~/SillyTavern/data/default-user/extensions/st-preset-workbench`。代码以 GitHub 当前分支为准，手机结果以用户实测为准。
